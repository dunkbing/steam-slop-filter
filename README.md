# Steam Slop Filter

> *Use slop to destroy the slops.*

A Chrome/Firefox extension that dims or hides AI-slop games on the Steam store.

A game is flagged when you voted it slop, or when the community did (at least 3 votes and 60% slop, both adjustable). You can also flag every game with a Steam AI disclosure.

## Install

- **Chrome:** `chrome://extensions` → Developer mode → *Load unpacked* → pick `extension/`.
- **Firefox:** `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on* → pick
  `extension/manifest.json`, then allow access to store.steampowered.com.
